# Personalized Webpage

A simple webpage that saves your name & age in localStorage, shows a personalized greeting, age in months, adult content check, and motivational quotes.

**Live Site:**https://david-mwonge123.github.io/personalised_webpage/
## How to run
1. **Clone the repo** -
   '''bash
   git clone https://github.com/David-Mwonge123/personalised_webpage
2. **Go into the project folder**
   cd personalised_webpage
3. Open in VS Code
   code .
4. **Open with Live Server**
   -Install Live Server extension in VS Code
   -Right-click index.html>Open with live server
   -Or just double-click index.html in file explorer
5. Enter Name and Age


## Features
- localStorage persistence
- if/else age check
- Template literals
- Function for age in months
- Loop for quotes
